## 💡 Overview & Background
**LearnCKB Indonesia** was created to bridge the knowledge gap for Indonesian developers exploring the unique architecture of Nervos Network (CKB). Adapted directly from the official **CKB Builder Handbook**, the platform provides structured, localized learning materials accompanied by code snippets, conceptual diagrams, and interactive quizzes for every module.

## 🚀 Key Features & Curriculum Structure

The platform organizes learning materials into **3 Core Phases** and **1 Resource Hub**:

### 🟢 1. Phase 1: Beginner
Focuses on fundamental concepts, local development setup, and basic on-chain transactions.
- **Lesson 1**: Introduction to Nervos CKB & Core Architecture (Layered Model, Cell Model).
- **Lesson 2**: Quick Start & Local Development Environment Setup with **OffCKB**.
- **Lesson 3**: Introduction to CKB Scripts (Lock Script & Type Script).
- **Lesson 4**: Practical Tutorial - Transfer CKB & Store Data on Cell.
- **Lesson 5**: Practical Tutorial - Token Issuance (sUDT) & Basic Spore DOBs.
- **Lesson 6**: Building a Simple Custom Lock & Exploring CKB DevTools (Faucet, Debugger, Explorer).
- **Lesson 7**: DApp Frontend Development using JavaScript/TypeScript & **CCC (Common Chain Connector)**.
- **Lesson 8**: Intensive Smart Contract Development with **Rust SDK** & **CKB-CLI**.
- **Lesson 9**: Alternative SDK Exploration (Go & Java).
- **Lesson 10**: Introduction to Layer 2 Payment Channels on CKB (**Fiber Network** & **Perun**).

### 🟡 2. Phase 2: Intermediate
Focuses on deep scripting theory, VM cycle optimization, and ecosystem token standards.
- **Script Development Course**: RISC-V VM Validation Model, WebAssembly on CKB, Advanced Debugging, and Type ID.
- **VM Optimization**: Duktape C runtime for on-chain JavaScript & cycle reduction techniques.
- **Molecule Serialization**: Deterministic, compact on-chain data serialization schema.
- **Ecosystem Standards**: In-depth sUDT (RFC 0025), Nervos DAO mechanisms (RFC 0023 & smart contract `dao.c`), and Spore DOB Protocol & Standalone Decoder.

### 🔴 3. Phase 3: Advanced
Focuses on high-level protocol innovation and Bitcoin interoperability.
- **xUDT (Extensible UDT - RFC 0052)**: Programmable fungible tokens with custom validation logic.
- **SSRI Protocol**: Script-Sourced Rich Information for decentralized on-chain metadata and execution.
- **RGB++ Protocol**: Isomorphic binding enabling smart contracts and Bitcoin assets via CKB.
- **iCKB**: Liquid staking protocol for tokenized Nervos DAO deposits.

### 📚 4. Resource Hub & Extra Reading
Architectural and conceptual reference library:
- Nervos Nation Visual Concepts
- Layered Blockchain Modularity
- Tokenomics & Sustainable Security (PoW + Cell Model)
- Account Abstraction without Accounts
- Blockchain Virtual Machine Comparison (CKB-VM vs EVM vs SVM vs WASM)
